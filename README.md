# FEFE40

A block-style 3D map of Casa Anahao (Tanauan, Batangas) for Filip's 40th birthday on 10 October.

Open `index.html` in any browser, on a phone or a computer:

- Drag to move, pinch or scroll to zoom, rotate with the arrow buttons.
- Tap a place (pool, dance floor, kitchen, bedroom, bathroom, bar and more) to fly there and see party details.
- Zoom into a building and its roof lifts off so you can see inside.

The room layout is approximate, built from the venue's public listing and photos.
